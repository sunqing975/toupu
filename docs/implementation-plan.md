# 开发实施计划

## 1. 目标

先交付可运行、可核算、可测试的最小投资账本，再逐步增加行情、导入、风险和 Agent。优先保证账务正确性，不以页面数量或 Agent 功能数量作为进度指标。

## 2. 里程碑

### M0：工程骨架

交付：
- FastAPI 项目结构。
- PostgreSQL Docker Compose。
- SQLAlchemy 2.x 和 Alembic。
- Pydantic 配置和统一错误响应。
- pytest、ruff、mypy（按团队需要）配置。
- `/health` 健康检查。
- `.env.example`、README、数据库迁移说明。

验收：空环境 `docker compose up` 可启动数据库和 API；Alembic 可从空库迁移；测试可运行。

### M1：基础账本

实现：
- 账户 CRUD。
- 标的 CRUD 和代码唯一性。
- 交易草稿创建、修改、确认。
- 账务科目初始化。
- PostingService。
- 借贷平衡校验。
- 交易幂等。
- 冲正。
- 审计日志。

验收：现金入金/出金、账户转账可以正确记账；不平衡分录不能过账；重复过账不会重复影响余额。

### M2：证券交易

实现：
- 股票/ETF 买入、卖出。
- 多笔成交归属同一交易业务。
- 成交费用记录。
- 持仓数量和成本。
- 部分成交和部分卖出。

验收：买卖交易的现金、数量、成本和已实现盈亏与人工核算一致。

### M3：场外基金

实现：
- 申购/赎回申请。
- 确认净值、份额、确认金额、费用。
- 不同平台/账户隔离。
- 基金分红和红利再投资。

验收：未确认申请不改变最终份额；确认后账本和持仓正确更新；不同渠道费率和持有批次不混淆。

### M4：导入和初始资产

实现：
- CSV/Excel 上传。
- 模板和字段映射。
- 原始行保存。
- 校验、重复检测、预览、人工确认。
- 期初现金和期初持仓导入。

验收：重复导入不会重复记账；导入错误可定位到行和字段；期初持仓不会伪造历史成交。

### M5：行情和收益分析

实现：
- Provider/Adapter 接口。
- 基金净值和股票/ETF 日行情。
- 数据质量和过期标记。
- 每日持仓/组合快照。
- 已实现/未实现盈亏。
- XIRR/TWR 和回撤。

验收：行情缺失时不伪装成实时；收益指标有定义文档和人工基准测试。

### M6：风险监控和 Agent

实现：
- 资产级、账户级、组合级风险规则。
- 风险事件和通知冷却。
- 投资计划和待审批提案。
- REST API 和 MCP 适配器。
- Agent token 和 scope。
- 自然语言记账只生成草稿。

验收：Agent 可以查询、分析和创建待审批提案；不能绕过用户审批直接写入正式账本或下单。

## 3. 第一周建议任务拆分

1. 初始化仓库和 Python 项目配置。
2. 建立 Docker Compose PostgreSQL。
3. 建立 SQLAlchemy Base、Session、Alembic。
4. 创建账户和标的模型及迁移。
5. 创建交易模型和状态枚举。
6. 创建账务科目、分录模型。
7. 实现借贷平衡 Domain Service。
8. 实现现金入金、出金、账户转账用例。
9. 编写事务回滚、幂等、冲正测试。

不要在第一周开发 AI 聊天、复杂仪表盘或多数据源行情。

## 4. 最小验收用例

### 现金入金

用户向证券账户入金 10,000 元：现金资产借方 10,000，期初/外部资金来源贷方 10,000；现金余额增加 10,000。外部资金流标签应记录为组合流入。

### 账户转账

证券账户转出 1,000 元到银行账户：证券账户现金减少 1,000，银行账户现金增加 1,000；组合总现金不变，组合外部现金流为零。

### 股票买入

买入 100 股，成交价 10 元，佣金 5 元：证券资产成本增加 1,005，证券账户现金减少 1,005，数量增加 100。

### 股票卖出

卖出部分持仓时，按当前成本方法计算出库成本；卖出净现金与出库成本差额计入已实现损益。持仓数量和成本同步减少。

### 基金申购

提交申请时不增加最终份额；收到确认数据后才生成持仓和对应账务记录。

## 5. 代码质量门槛

每个 PR/任务至少执行：

- `pytest` 相关测试。
- `ruff check`。
- `ruff format --check`。
- Alembic migration 检查（涉及 schema 时）。
- 关键业务场景人工核算对照。

没有实际执行的检查必须标记“未运行”，不得声称通过。

## 6. 暂缓事项

- 多市场和多币种。
- 券商 API 自动同步。
- 自动交易。
- Redis/Kafka/Celery。
- 多 Agent 协作。
- 高级量化回测。
- 复杂税务申报。

只有出现真实需求后才引入。
