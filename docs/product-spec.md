# 产品规格 product-spec · 投谱 Toupu v0.0.1

> 产品文档与系统设计文档（docs/）配套。本文回答"做什么、给谁用、做到什么程度"。

## 1. 产品定位

**投谱**是个人投资资产管理与决策系统：把散落在券商、基金平台、银行卡里的投资活动记成一本**可信的账**，在此基础上提供持仓核算、收益分析和风险提醒，辅助（而不是替代）投资决策。

- 单用户、本地部署、数据可迁移。
- 第一版仅支持中国市场：场外公募基金、场内 ETF、A 股股票、现金账户；统一 CNY。
- 明确不是：自动交易系统、投资建议服务、多用户 SaaS。

## 2. 用户画像与核心任务

用户 = 系统唯一的使用者和管理者。同时扮演两种角色：

| 角色 | 关注点 | 对应功能 |
|---|---|---|
| 记账员 | 快、准、不重复地录入交易 | 手动录入、导入、草稿确认 |
| 投资人 | 我的钱怎么样了、该注意什么 | 总览、持仓、收益、风险、复盘 |

核心任务（按优先级）：

1. **记录**：入金/出金/转账、股票/ETF 买卖、基金申赎、分红送转，全部可追溯。
2. **核算**：现金余额、持仓数量与成本（移动加权平均）、已实现/未实现盈亏。
3. **核对**：Excel/CSV 导入对账，期初资产导入，不重复记账。
4. **决策支持**：收益指标（XIRR/TWR/回撤）、风险规则提醒、投资计划与待审批提案（Agent 辅助）。

## 4. 关键产品原则（从 docs/agent.md 提炼）

1. **账本是唯一事实**。页面上的余额、持仓、收益全部可追溯到已过账分录；不提供任何"直接改余额"的入口。
2. **录入≠入账**。草稿可随意改；入账必须经确认且借贷平衡；已入账只能冲正，不能改删。
3. **确定性优先**。所有金额计算、风险判断由代码完成；LLM 只解释和提案，写操作必须人工审批。
4. **缺失不伪装**。行情缺失/过期时明确显示，不用旧数据冒充实时。

## 5. 界面功能总述

界面分三层信息密度：

- **总览层**：我现在的财务状况一屏看清（总资产、现金、持仓市值、累计收益、风险提示数、待处理数）。
- **流水层**：交易、账本分录的记录与管理（新增、确认、过账、冲正）。
- **分析层**：持仓结构、收益走势、风险事件（随 M5/M6 逐步充实）。

前端跟随里程碑逐步实现：v0.1 覆盖 P0+P1 页面，v0.2 补齐 P2。

## 6. 成功标准

1. 手动录入一笔买入，5 秒内完成，余额/持仓/成本立即正确。
2. 导入一份对账单，重复导入不产生重复记账，错误可定位到行和字段。
3. 任意持仓和余额可从账本分录重建，页面展示与人工核算一致。
4. Agent 在没有审批的情况下无法改变任何账本数据。
