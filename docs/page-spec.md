# 页面规格 page-spec · 投谱 Toupu

> 信息架构与逐页功能规格。每页标注里程碑归属与数据来源（API）。布局规范由 UI/UX 设计阶段补充。

## 0. 信息架构

```
总览 Dashboard (/)                     P0/M5 增强
持仓 Positions (/positions)            P1/M2
交易 Transactions (/transactions)      P0/M2/M3
  ├─ 列表页 (/transactions)
  ├─ 新建 (/transactions/new)          按类型分表单
  └─ 详情 (/transactions/:id)          含分录、成交、确认、冲正链
账本 Ledger (/ledger)                  P0/M1 只读
导入 Imports (/imports)                P1/M4
  └─ 向导（上传→映射→预览→确认）
账户 Accounts (/accounts)              P0 已实现后端
标的 Instruments (/instruments)        P0 已实现后端
分析 Analytics (/analytics)            P2/M5
风险 Risk (/risk)                      P2/M6
设置 Settings (/settings)              P2
```

## 1. 总览 Dashboard（/）｜P0，M5 增强

- **目的**：一屏回答"我现在怎么样"。
- **区块**：
  1. 资产卡：总资产、现金合计、持仓市值（M5 前显示持仓成本）。
  2. 收益卡：已实现盈亏、未实现盈亏（M2/M5）、累计出入金。
  3. 待办条：DRAFT/CONFIRMED 待处理交易数、待审批提案数。
  4. 风险条：未处理风险事件数（M6）。
  5. 近期交易列表（最近 10 条，跳详情）。
  6. 资产构成图（M5）。
- **空态**：初始化向导引导（见 user-flow §2）。
- **数据**：`/api/v1/accounts`、`/api/v1/transactions`；M5 起用快照接口。

## 2. 交易列表（/transactions）｜P0

- **目的**：交易事实的唯一管理入口。
- **布局**：筛选栏（账户、类型、状态、日期范围）+ 表格。
- **表格列**：日期、类型、账户、标的/摘要、金额、状态徽标、操作（确认/过账/冲正/查看）。
- **状态徽标**：DRAFT 灰 / CONFIRMED 蓝 / PARTIAL 黄 / POSTED 绿 / REVERSED 橙 / CANCELLED 划线。
- **操作规则**：DRAFT 可编辑删除；CONFIRMED 可过账可退回草稿；POSTED 只能冲正；REVERSED 只读。
- **数据**：`/api/v1/transactions`（M1 实现中）。

## 3. 交易新建（/transactions/new）｜P0/M2/M3

- **目的**：按业务类型给出精确表单，不允许"一张大表单适配一切"。
- **表单按类型**：
  | 类型 | 字段 |
  |---|---|
  | 入金/出金 | 账户、金额、日期、备注 |
  | 转账 | 转出账户、转入账户、金额、日期 |
  | 股票/ETF 买卖 | 账户、标的、成交明细（多笔：日期/数量/价格/费用）、备注 |
  | 基金申购/赎回 | 账户、标的、申请金额/份额、平台、费率预估、日期 |
  | 期初余额 | 账户、期初现金 或 期初持仓（数量+成本+口径来源） |
- **保存**：默认存 DRAFT；金额校验（>0）、余额校验（过账时才做，草稿不限）。
- **幂等**：重复提交同一表单生成提示而非第二条交易。

## 4. 交易详情（/transactions/:id）｜P0

- **区块**：
  1. 头部：类型、状态、日期、金额、账户/标的。
  2. 成交明细表（证券类）/ 确认信息卡（基金类）。
  3. 账务分录：借/贷分录表（POSTED 后显示），含分录合计校验展示。
  4. 冲正链：若被冲正/是冲正，显示关联交易链接。
  5. 操作区：按状态显示 确认/过账/冲正/作废。
- **数据**：`/api/v1/transactions/{id}`、`/api/v1/ledger/entries`、`/api/v1/transactions/{id}/reverse`。

## 5. 账本 Ledger（/ledger）｜P0 只读

- **目的**：让用户能直接检查"钱是怎么变的"，是可审计性的页面表达。
- **布局**：分录列表（日期、交易、借方合计、贷方合计、平衡✓），展开显示 journal lines（科目、方向、金额）。
- **筛选**：账户、科目类型、日期。
- **禁止**：任何写操作入口。

## 6. 持仓 Positions（/positions）｜P1/M2

- **目的**：按账户分组的当前持仓。
- **布局**：账户分组卡片 → 组内表格：标的、数量、单位成本、总成本、剩余批次展开。
- **口径**：数量/成本来自 lot 与分录，可重建；批次明细标注 lot_origin（TRADE/OPENING_BALANCE）。
- **数据**：`/api/v1/positions`（M2）。

## 7. 账户管理（/accounts）｜P0（后端已实现）

- **列表**：名称、类型徽标、币种、状态、备注；新建/编辑弹窗。
- **类型**：BROKER/FUND_PLATFORM/BANK/CASH；状态 ACTIVE/FROZEN/CLOSED。
- **删除保护**：被账本引用 → 409，页面提示改用"关闭"。
- **数据**：`/api/v1/accounts` ✅。

## 8. 标的管理（/instruments）｜P0（后端已实现）

- **列表**：类型、市场、代码、名称、状态；筛选（类型）。
- **新建**：类型（FUND/ETF/STOCK）、market+code 唯一（重复 409）、基金可无 exchange。
- **数据**：`/api/v1/instruments` ✅。

## 9. 导入向导（/imports）｜P1/M4

- **步骤条**：上传 → 模板与字段映射 → 预览校验 → 确认入账。
- **预览页**：每行状态（可入/警告/错误+行号+字段+原因），可排除行。
- **确认后**：显示导入结果（成功/失败计数），失败行保留可导出。

## 10. 分析（/analytics）｜P2/M5

- 收益走势（组合净值线）、账户对比、XIRR/TWR、最大回撤、已实现/未实现瀑布。
- 口径说明固定展示（外部现金流定义、估值来源与时间）。

## 11. 风险（/risk）｜P2/M6

- 事件列表（级别、规则、触发值、时间）、处理/忽略操作、规则管理入口（设置内）。

## 12. 设置（/settings）｜P2

- 风险规则管理、Agent Token 与 scope、通知渠道、成本方法展示（只读，改口径需文档变更）。

## 13. 全局规范（待 UI/UX 阶段细化）

- 金额/份额显示：十进制字符串来源，展示层格式化，不回写；来源精度不足时显示原始精度。
- 所有列表分页；所有破坏性操作二次确认并说明后果。
- 状态徽标、错误提示、空态文案全局统一。
